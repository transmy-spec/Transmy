# Contribuer

Le projet est distribue sous licence AGPL-3.0-only. Toute contribution doit pouvoir etre
publiee sous cette licence et comporter un certificat d'origine (`Signed-off-by`) conforme au
Developer Certificate of Origin 1.1.

## Proposer une modification

1. Ne jamais utiliser de donnee reelle ou pseudonymisee dans le code, les tests ou les captures.
2. Creer une branche courte et une modification limitee a un objectif.
3. Ajouter les tests positifs, les refus d'autorisation et les preuves d'audit necessaires.
4. Executer les commandes de verification du `README.md`.
5. Documenter les migrations, impacts de securite et actions d'exploitation.
6. Ajouter `Signed-off-by: Nom <adresse>` au message de commit.

Les changements de schema, d'habilitation, de conservation ou de journalisation demandent une
revue explicite. Une contribution ne doit pas affaiblir les controles pour simplifier un test.
